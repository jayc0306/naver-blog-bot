# 스타일 노트 (프롬프트에 그대로 들어감)
# 크리에이터 어드바이저 TOP20에서 잘 터진 글의 교집합을 찾으면 여기에 계속 추가할 것.

## 제목 (홈판 + 검색 둘 다 노림)
- 정책명을 제목 맨 앞에. 그 뒤에 신청방법·대상·금액·기간 중 하나 + 후킹.
- 후킹 유형을 섞는다: 숫자형("최대 330만원"), 손실회피형("이번 달 안 하면 끝"), 비교형("작년과 달라진 3가지"), 궁금증형("나도 받을 수 있을까"), 검색형("OO 신청방법 대상 기간 총정리").
- 제목이 던진 질문은 본문 첫 소제목에서 바로 답한다. 금액은 '최대'인지 '일괄'인지 정확히. 과장 금지.

## 본문
- 1,200~1,800자. 모바일 기준 1~2문장마다 줄바꿈.
- 첫 3줄: 누가, 얼마, 언제까지.
- 소제목 3~4개: 핵심 요약 → 대상·조건 → 신청 방법 → 주의할 점/자주 묻는 것.
- 친구한테 "너 이거 신청했어?" 하듯. 키워드 억지 반복 금지.

## 이미지
- 숫자 강조 카드 4~5장 + 직접 캡처한 신청 화면 1~2장.
- 첫 카드가 대표 이미지(썸네일). '얼마'와 '언제까지'가 한눈에.
