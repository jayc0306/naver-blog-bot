# 스타일 노트 (프롬프트에 그대로 들어감)
# 크리에이터 어드바이저 TOP20에서 잘 터진 글의 교집합을 찾으면 여기에 계속 추가할 것.

## 제목 (홈판 + 검색 둘 다 노림)
- 작품명·인물명을 제목 맨 앞에. 그 뒤에 검색형 정보어(몇부작, 출연진, OTT, 촬영지)나 후킹.
- 후킹 유형을 섞는다: 숫자형("시청률 2배"), 손실회피형("이거 모르고 보면 헷갈림"), 비교형("원작과 다른 점"), 궁금증형("왜 이 배우였을까"), 검색형("OO 몇부작 출연진 OTT 총정리").
- 제목이 던진 질문은 본문 첫 소제목에서 바로 답한다. 낚시 금지. 사실과 다른 과장 금지.

## 본문
- 900~1,500자. 모바일 기준 3~4줄(2~3문장)마다 문단 띄우기.
- 첫 3줄에 핵심 정보(언제, 어디서, 몇부작)를 먼저.
- 소제목 3~4개: 기본 정보 → 출연진/등장인물 → 관전 포인트 → 어디서 보나.
- 친구한테 "이거 봤어?" 하듯 가볍게. 키워드 억지 반복 금지.

## 이미지
- 텍스트 카드 4~5장 + 공식 유튜브 영상 임베드 1개.
- 첫 카드가 대표 이미지(썸네일). 홈판에서 엄지를 멈추게 하는 한 줄.


## 홈판 운영 원칙 (머니대외비 홈판 가이드, 2026.10)
- 홈판 AI가 제일 보는 건 체류시간. 이미지는 소제목 밑에 몰지 말고 설명 문단 사이사이에, 2~3문단마다 하나.
- 문단은 모바일 기준 3~4줄마다 띄운다. 너무 잘게 끊지도, 빽빽하게 붙이지도 않는다.
- 제목은 피드를 넘기던 손가락을 멈추게: 궁금증·반전·숫자·인용(따옴표)·말줄임표. AI 제목은 그대로 쓰지 말고 내 말투로 2차 가공.
- 크리에이터 어드바이저 '메인 유입 트렌드' 상위 글 제목 패턴을 계속 벤치마킹 (텔레그램 '트렌드' 명령).
- 발행은 오전 7시~오후 7시. 발행 직후 1~2시간 반응이 초기 부스팅을 결정.
- 한 계정에 검색용 글과 홈판용 글을 섞지 않는다.
- 2주~한 달 꾸준히 쌓아야 일 100~200에서 어느 날 갑자기 1만 이상으로 뛰는 구간이 온다. 하루 이틀 조회수로 판단하지 않는다.
